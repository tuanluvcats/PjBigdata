6.	Yêu cầu
	Các nội dung cụ thể cần thực hiện:
	Phân tích yêu cầu nghiệp vụ và thiết kế kiến trúc hệ thống theo hướng Microservices, thiết kế cơ sở dữ liệu lưu trữ thông tin giao dịch tài chính.
	Thiết kế giao diện UI/UX và lập trình hoàn chỉnh ứng dụng di động bằng Flutter, kết hợp xây dựng Web Admin Dashboard.
	Thu thập, xử lý và chuẩn hóa tập dữ liệu hóa đơn tiếng Việt.
	Nghiên cứu kiến trúc mô hình DONUT theo hướng tiếp cận End-to-End OCR-free.
	Nghiên cứu giải pháp mở rộng bộ Tokenizer tiếng Việt cho mô hình.
	Tiến hành huấn luyện mô hình DONUT để thực hiện tác vụ trích xuất thông tin hóa đơn tiếng Việt thành 4 trường: Seller, Address, Timestamp, Total Cost. 
	Xây dựng các phương thức hậu xử lý bằng biểu thức chính quy Regex để chuẩn hóa dữ liệu trích xuất.
	Xây dựng hệ thống API RESTful kết nối Backend Java Core, AI Service và Mobile App thành quy trình tự động hóa hoàn chỉnh. Kiểm thử, đóng gói Docker và triển khai hệ thống.
7.	Môi trường thực hiện
	Yêu cầu về Ngôn ngữ: Sử dụng Java kết hợp Spring Boot cho hệ thống Backend Core. Python và FastAPI để huấn luyện DONUT OCR-free và xây dựng AI Service. Flutter/Dart để lập trình ứng dụng Mobile. HTML, CSS, JavaScript kết hợp Thymeleaf cho giao diện Web Admin Dashboard.
	Yêu cầu về hệ quản trị: Sử dụng PostgreSQL để lưu trữ thông tin giao dịch, kết hợp bộ nhớ đệm nhằm tối ưu tốc độ cho các truy vấn thống kê.
	Yêu cầu khác: Huấn luyện AI bằng tài nguyên GPU trên Kaggle. Đóng gói và triển khai hệ thống bằng Docker trên máy chủ ảo VPS. Kiểm thử và tài liệu hóa qua Postman, JMeter, Swagger. Quản lý mã nguồn bằng Git/GitHub.
